  <files>tmc-characters-maker/components/RichTextSectionEditor.tsx</files>
  <action>
Create `tmc-characters-maker/components/RichTextSectionEditor.tsx` (`'use client'`):
- Props:
  - `section: Section`
  - `onUpdate: (updates: Partial<Section>) => void`
- Features:
  1. **Title Input:** Optional section heading input matching the existing `CharacterEditor` academy mono input aesthetic (`var(--surface-alt)`, `var(--border-light)`, `var(--text)`).
  2. **Inline Formatting Toolbar:** Compact, clean button strip with tooltips (`title` attributes in Spanish to match the app UI):
     - Basic: Bold (`[b]...[/b]`), Italic (`[i]...[/i]`), Underline (`[u]...[/u]`), Strikethrough (`[s]...[/s]`).
     - Sci-fi Effects: Glitch (`[glitch]...[/glitch]`), Crisp (`[crisp]...[/crisp]`), Old Comm Quote (`\n[comm:REGISTRO]\n...\n[/comm]\n`), Classified/Redacted (`[redacted]...[/redacted]`).
     - Structure: Paragraph Break (`\n\n`) and Story Divider (`\n[hr]\n`).
     - Uses a `textareaRef` so clicking any toolbar button wraps `selectionStart..selectionEnd` (or inserts a helpful placeholder when empty) and restores focus/selection cleanly via `requestAnimationFrame`.
  3. **Story Textarea:** Taller resizable textarea (`minHeight: '130px'`) with helpful placeholder mentioning `Enter` for line breaks and toolbar effects.
  4. **Collapsible "Estilo de Sección" Controls** (keeps the sidebar clean & uncluttered):
     - **Alineación:** 4 icon buttons (`left`, `center`, `right`, `justify`).
     - **Contenedor:** 3 pill buttons (`Plano` / `Tarjeta` / `Dossier`).
     - **Tamaño:** 3 pill buttons (`S` / `M` / `L`).
     - **Fuente (opcional):** Select dropdown with "Heredar de la ficha" + all loaded app fonts (`Inter`, `Lato`, `Montserrat`, `Roboto`, `Cormorant Garamond`, `Playfair Display`, `Cinzel`, `Libre Baskerville`, `Monospace`).
     - **Color de texto (opcional):** Color picker + "Restablecer" clear button so users can override or inherit sheet `text_color`.
  </action>
  <verify>TypeScript compiles cleanly with no unused imports or type errors.</verify>
  <done>`RichTextSectionEditor.tsx` provides complete inline formatting + per-section customization in a clean, self-contained component.</done>
</task>
