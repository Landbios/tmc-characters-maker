<task type="auto">
  <name>Task 2: Implement deterministic rich text parser in utils/richText.ts</name>
  <files>tmc-characters-maker/utils/richText.ts</files>
  <action>
Create `tmc-characters-maker/utils/richText.ts` with a pure, dependency-free parser that converts a raw string into structured blocks and inline nodes (no HTML strings, no regex backtracking traps):

1. **Block-level constructs (`RichTextBlock`):**
   - `comm`: `[comm]...[/comm]` or `[comm:HEADER]...[/comm]` (case-insensitive tag matching; supports multi-line content inside the transmission quote, parsed for inline formatting and line breaks).
   - `divider`: a line containing `[hr]` or `---` (trimmed) becomes a subtle story divider block.
   - `paragraph`: contiguous text lines separated by one or more blank lines (`\n\n+`). Single newlines (`\n`) inside a paragraph become `{ type: 'br' }` inline nodes so explicit line breaks always render.

2. **Inline-level constructs (`RichTextInline`):**
   - `text`: plain string segment
   - `br`: explicit line break (`\n`)
   - `bold`: `[b]...[/b]`
   - `italic`: `[i]...[/i]`
   - `underline`: `[u]...[/u]`
   - `strike`: `[s]...[/s]`
   - `glitch`: `[glitch]...[/glitch]`
   - `crisp`: `[crisp]...[/crisp]`
   - `redacted`: `[redacted]...[/redacted]`
   - Support safe nesting (e.g., `[b][crisp]text[/crisp][/b]`) with a recursion depth guard (e.g. max depth 6).
   - Graceful fallback: if an opening tag has no matching closing tag, emit the opening tag as plain text and continue parsing so nothing is ever lost or broken while typing.
  </action>
  <verify>Verify parser handles plain text, `\n`, `\n\n`, `[hr]`, `[comm]`, `[comm:FREQ-04]`, nested tags, and unclosed tags cleanly.</verify>
  <done>`utils/richText.ts` exports `parseRichText`, `RichTextBlock`, and `RichTextInline` with zero external dependencies.</done>
</task>
