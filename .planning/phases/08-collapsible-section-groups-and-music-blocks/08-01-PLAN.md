<task type="auto">
  <name>Task 2: Create strict YouTube URL utility in utils/youtube.ts</name>
  <files>tmc-characters-maker/utils/youtube.ts</files>
  <action>
Create `tmc-characters-maker/utils/youtube.ts`:
- `extractYouTubeId(rawUrl?: string): string | null`:
  - Accepts `https://www.youtube.com/watch?v=...`, `https://youtu.be/...`, `https://youtube.com/shorts/...`, `https://youtube.com/embed/...`, `https://music.youtube.com/watch?v=...` (and optional protocol-less or bare 11-char ID if needed, strictly validated with `/^[a-zA-Z0-9_-]{11}$/`).
  - Uses `new URL(...)` inside `try/catch` and verifies hostname is a valid YouTube domain (`youtube.com`, `www.youtube.com`, `m.youtube.com`, `music.youtube.com`, `youtu.be`, `www.youtube-nocookie.com`).
  - Returns `null` for any invalid or non-YouTube URL.
- `getYouTubeEmbedUrl(videoId: string, options?: { autoplay?: boolean; loop?: boolean }): string`:
  - Uses `https://www.youtube-nocookie.com/embed/${videoId}` with safe query params (`autoplay=1`, `loop=1&playlist=${videoId}`, `rel=0`, `modestbranding=1`).
- `getYouTubeThumbnailUrl(videoId: string): string`:
  - Returns `https://i.ytimg.com/vi/${videoId}/hqdefault.jpg`.
- `getYouTubeWatchUrl(videoId: string): string`:
  - Returns `https://www.youtube.com/watch?v=${videoId}`.
  </action>
  <verify>Handles standard, shortened, shorts, music.youtube.com, and invalid URLs safely.</verify>
  <done>`utils/youtube.ts` exports all 4 helper functions.</done>
</task>
