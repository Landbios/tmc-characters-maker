# Integrations

## Backend as a Service
- **Supabase**: Handles Authentication, Database (PostgreSQL), and Storage (for character images). Supabase SSR package is used for server-side auth rendering.

## Internal APIs
- The Next.js App Router exposes API routes under `app/api/`.

- Discord Bot (Tupperbox style integration)
