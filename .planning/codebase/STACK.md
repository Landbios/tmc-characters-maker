# Tech Stack

## Overview
Next.js (Vercel) + Supabase application for TMC Character Creation Vault.

## Core Technologies
- **Framework**: Next.js 15.4.9 (App Router)
- **UI Library**: React 19.2.1
- **Styling**: Tailwind CSS 4.1.11, `lucide-react`, `motion`
- **State Management**: Zustand (`zustand` 5.0.11)
- **Database / Auth**: Supabase (`@supabase/ssr` 0.9.0, `@supabase/supabase-js` 2.98.0)
- **Forms**: `react-hook-form` with `@hookform/resolvers`
- **Drag and Drop**: `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`
- **Components**: Radix UI primitives (`@radix-ui/react-label`, `slider`, `slot`, `switch`, `tabs`)
- **Utilities**: `class-variance-authority`, `clsx`, `tailwind-merge`
- **Exporting**: `html2canvas-oklch`, `jspdf`
- **Image Cropping**: `react-easy-crop`
